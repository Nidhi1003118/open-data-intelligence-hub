# 🛒 E-Commerce Recommendation System

## 📌 Project Overview
This project builds an E-Commerce Recommendation System using Machine Learning techniques to analyze customer and product data. The system helps recommend products based on customer preferences and product features. It also includes data preprocessing, exploratory data analysis, model building, and performance evaluation.

---

## 🚀 Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Product Recommendation
- Machine Learning Model using Ridge Regression
- Model Evaluation using MAE, RMSE, and R² Score
- Data Visualization

---

## 📊 Workflow
1. Load the dataset.
2. Clean and preprocess the data.
3. Perform Exploratory Data Analysis (EDA).
4. Encode and transform required features.
5. Train the Ridge Regression model.
6. Evaluate model performance.
7. Generate product recommendations.

---

## 📈 Model Evaluation
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/akshara-a/open-data-intelligence-hub.git
```

2. Open the project folder.

3. Install dependencies.

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

4. Open the notebook.

```bash
jupyter notebook recommendation.ipynb
```

5. Run all cells.
