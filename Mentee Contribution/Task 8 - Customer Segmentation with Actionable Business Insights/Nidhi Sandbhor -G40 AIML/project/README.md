# Task 8: Customer Segmentation with Actionable Business Insights

## 📌 Project Overview

This project focuses on customer segmentation using Machine Learning techniques. The objective is to group customers based on their purchasing behavior and generate actionable business insights that help improve marketing strategies and customer engagement.

The project uses the **Customer Personality Analysis** dataset and implements clustering, regression, classification, and hyperparameter tuning.

---

## 📂 Dataset

Dataset Used: Customer Personality Analysis

The dataset contains customer demographic information, purchasing behavior, income, spending habits, website visits, and campaign responses.

### K-Means Clustering

- Silhouette Score

- Predict Customer Spending
- Evaluation:
  - MAE
  - RMSE
  - R² Score

### Logistic Regression
- Predict Customer Purchase Response
- Evaluation:
  - Accuracy
  - Precision
